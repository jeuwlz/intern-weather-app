The folder named "ArduinoServer" contains the files related to the server that the Arduino UNO connected to via Wi-Fi.  

The folder named "ArduinoUno" contains a single .INO file with the programming for the Arduino UNO. 

The folder named "WeatherDataSystem" contains subfolders including: API (REST API), DataSorter (data sorter program), UI (windows forms app UI). 


Technologies used:
Arduino UNO
C#/.NET 
ASP.NET Cote
Windows Services
SQL Server (not in respository)
JWT Authentication
Windows Forms
Wi-Fi communication
